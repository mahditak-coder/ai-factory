# providers/ — مدیریت API و مدل‌ها

## نکات مهم امنیتی
- **هرگز** کلیدهای API را در فایل‌های این پوشه (یا هیچ فایل عمومی) ذخیره نکنید.
- کلیدها را فقط از طریق متغیرهای محیطی Termux وارد کنید:

```bash
export OPENCODE_API_KEY="..."
```

## فعال‌سازی مدل
فایل `models.json` مشخص می‌کند کدام مدل فعال است.
سرور به‌طور خودکار نسخه‌ی OpenCode نصب‌شده را به آن اضافه می‌کند.
