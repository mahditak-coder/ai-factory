مدیریت

بار اول است؟ یک «رمز مدیر» تنظیم کنید تا تغییر تنظیمات فقط با این رمز ممکن شود. این رمز هرگز به مرورگر ذخیره/برگشت داده نمی‌شود (فقط hash سمت سرور).

اتصال به سرویس

همهٔ تغییرهای ذخیره نمی‌شوند مگر دکمهٔ ذخیره — فقط فیلدهای عوض‌شده ارسال می‌شوند تا بقیه‌ی تنظیمات پاک نشود. «تست» اول فیلدهای عوض‌نشدهٔ فعلی را می‌سنجد؛ اگر تغییری هست همان هم لحاظ می‌شود.

کلید API فقط سمت سرور (فایل خصوصی ۰۶۰۰) ذخیره می‌شود و از این صفحه هرگز خواندنی/برگشتی نیست.
