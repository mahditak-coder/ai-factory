# agents/ — عامل‌های هوش مصنوعی

این پوشه محل نگهداری پیکربندی و اسکریپت‌های عامل‌های (Agent) هوش مصنوعی است.

## چیدمان پیشنهادی
- `agents/<agent-name>/agent.json` — پیکربندی عامل
- عامل‌ها از طریق OpenCode اجرا می‌شوند، نه از طریق این سرور محلی.

سرور مدیریتی AI Factory هیچ دستور دلخواهی را از طریق پنل اجرا نمی‌کند؛
اجرای عامل‌ها فقط از ترمینال و با ابزارهای واقعی انجام می‌شود.

## AF-24 — ابزار انتشار هوشمند (برای عامل‌ها)

عامل‌ها (از جمله `builder` و `releaser`) وقتی با درخواست انتشار فارسی روبهرو
می‌شوند، **عملیات واقعی** را اجرا میکنند، نه اینکه فقط دستور بدهند:

```bash
cd /data/data/com.termux/files/home/AI-Factory
./scripts/ai-factory-smart-release --request "متن دقیق درخواست کاربر" \
    [--project نام-پروژه] [--confirm] [--plan]
```

همین عملیات از API محلی (`127.0.0.1:8580`) هم قابل فراخوانی است:
`POST /api/smart-release/chat` با بدنهٔ `{"text": "…", "project": "…"}`.
پاسخ، گزارش واقعی (شامل SHA256، مسیر فایل، وضعیتها) است؛ عامل نباید آن را
حدس بزند یا جعل کند. جزئیات: `docs/SMART_RELEASE.md`.
